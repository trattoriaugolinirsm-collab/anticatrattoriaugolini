# Deploy Antica Trattoria Ugolini

Cartella da pubblicare: `atusitev5_work`

## GitHub

1. Crea un account su https://github.com se non ne hai uno.
2. Crea un nuovo repository, per esempio `antica-trattoria-ugolini`.
3. Carica tutti i file di questa cartella nel repository.

## Vercel

1. Crea un account su https://vercel.com usando lo stesso account GitHub.
2. Clicca `Add New Project`.
3. Importa il repository GitHub.
4. Lascia vuoti i campi di build:
   - Framework preset: `Other`
   - Build command: vuoto
   - Output directory: vuoto
5. Clicca `Deploy`.

## Dopo il deploy

1. Copia l'URL Vercel provvisorio.
2. Quando il dominio definitivo sara pronto, collega `anticatrattoriaugolini.com` da `Settings > Domains`.
3. In Google Search Console aggiungi il dominio e invia `https://anticatrattoriaugolini.com/sitemap.xml`.
